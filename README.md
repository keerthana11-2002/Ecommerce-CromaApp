**Automation Framework for Testing Croma E-Commerce Website**
**Project Overview**

This project is a Selenium-based automation framework designed to test key functionalities of the Croma e-commerce website. It focuses on validating search, filtering, sorting, pricing, and major user flows to ensure a reliable and smooth shopping experience.

**Application Under Test**
🔗 https://www.croma.com/

**Domain**

E-Commerce / Online Retail

**Tools & Technologies**
Java

Selenium WebDriver

TestNG

Maven

Extent Reports

Apache POI (Excel – data-driven testing)

Log4j (logging)

**Key Test Scenarios**

Product search validation (Refrigerator)

Brand filtering (Samsung, LG, Whirlpool)

Sorting by highest discount

Average price calculation of top 10 discounted products

Screenshot capture at critical steps

Log generation and Extent Report creation

Additional Scenarios

Add to Cart validation

Product comparison

User login & registration

Checkout process verification

**Framework Highlights**

Data-driven testing using Excel

Modular and reusable TestNG structure

Automatic screenshot capture

Detailed logs and professional reports
